# Тараканьи бега 🪳

Онлайн-гонка для тренировки скоростной печати на русском. Каждый игрок набирает один и тот же текст, а его таракан бежит по дорожке ровно настолько, насколько далеко продвинулся набор. Кто первым без ошибок наберёт весь текст, тот и победил.

## Как это работает

- **Вход по нику.** Никаких паролей: вписал ник и в бой. Ник запоминается в браузере.
- **Общий заезд.** Кнопка «В гонку» сажает в ближайший свободный заезд (до 8 тараканов). Когда собралось двое и больше, через 15 секунд старт. Можно не ждать и стартовать одному.
- **Комнаты для друзей.** «Создать комнату» выдаёт код и ссылку вида `https://ваш-домен/?room=K7QX`. Заезд запускает тот, кто зашёл первым. Кто пришёл посреди заезда, бежит в следующем.
- **Набор.** Пока стоит ошибка, таракан не двигается: её надо стереть Backspace. Буквы «е» и «ё» считаются одинаковыми. Если включена английская раскладка, игра подскажет.
- **Результаты.** Скорость в знаках в минуту, точность и время. Лучший результат каждого ника попадает в таблицу «Самые быстрые», она хранится в `/data/records.json`.

## Запуск у себя

Нужен Node.js 18 или новее.

```bash
npm install
npm start
```

Открой http://localhost:3000. Чтобы погонять самому с собой, открой вторую вкладку и зайди в ту же комнату по коду.

## Структура

```
server.js          сервер: Express + Socket.IO, комнаты, логика заезда, рекорды
texts.js           тексты для заездов (добавляй свои)
public/index.html  разметка
public/style.css   оформление
public/track.js    трасса и тараканы на canvas
public/app.js      вход, набор текста, табло
Dockerfile         сборка контейнера
amvera.yml         конфигурация для Amvera (Docker, порт 3000, хранилище /data)
```

## Деплой на Amvera

Конфигурация уже лежит в `amvera.yml`: проект собирается из `Dockerfile`, приложение слушает порт 3000, рекорды сохраняются в постоянное хранилище `/data`.

1. В личном кабинете Amvera создай новое приложение.
2. Подключи код одним из двух способов:
   - **Через GitHub.** В настройках проекта привяжи свой репозиторий: укажи токен GitHub, выбери репозиторий и ветку `master`. После этого каждый `git push` в GitHub будет сам пересобирать и перезапускать приложение.
   - **Через репозиторий Amvera.** Добавь второй remote и пушь в него:
     ```bash
     git remote add amvera https://git.amvera.ru/<логин-amvera>/<имя-проекта>
     git push amvera master
     ```
     Логин и пароль при пуше от учётной записи Amvera.
3. Дождись окончания сборки и включи бесплатный домен в настройках приложения.
4. Открой домен: на главной должно быть «Тараканьи бега».

Проверка, что сервер жив: `https://ваш-домен/health` отвечает `ok`.

## Настройки

Всё в начале `server.js`:

| Константа | Что значит | По умолчанию |
|---|---|---|
| `MAX_PLAYERS` | тараканов в заезде | 8 |
| `AUTOSTART_MS` | через сколько стартует общий заезд, когда собралось 2+ | 15 с |
| `COUNTDOWN_MS` | обратный отсчёт перед стартом | 3 с |
| `RESULTS_MS` | сколько висят результаты | 12 с |
| `MAX_CPS` | порог против читов, знаков в секунду | 25 |

Переменные окружения: `PORT` (порт, по умолчанию 3000) и `DATA_DIR` (куда писать рекорды, в Docker это `/data`).

## Что стоит знать

- Состояние заездов живёт в памяти сервера, поэтому запускай **один инстанс**. После перезапуска текущие заезды обрываются, рекорды остаются.
- Ник никак не защищён: кто угодно может войти под чужим ником. Для дружеских гонок этого хватает.
- Защита от читов простая: сервер не принимает прогресс быстрее 25 знаков в секунду и вставку текста. Набить вручную всё равно придётся.
