# Тараканьи бега: контекст для Claude Code

Онлайн-гонка для тренировки скоростной печати на русском. Игроки набирают один и тот же текст, таракан каждого бежит по дорожке пропорционально набранному. Побеждает тот, кто первым правильно наберёт весь текст. Интерфейс и тексты только на русском.

## Стек
- Node.js 20, Express 4, Socket.IO 4. Без базы данных, без сборки фронтенда.
- Клиент: чистый JS + canvas (`public/`), подключается как обычные `<script>`.
- Хостинг: Amvera Cloud через `Dockerfile` + `amvera.yml` (порт 3000, постоянное хранилище `/data`).
- Репозиторий: GitHub, ветка `master`. Amvera пересобирает приложение по пушу в привязанный репозиторий.

## Команды
- `npm install` установить зависимости
- `npm start` запустить сервер на http://localhost:3000
- `npm run dev` то же с автоперезапуском
- `curl localhost:3000/health` должен ответить `ok`

## Архитектура
- `server.js` вся серверная логика: комнаты (`rooms` Map), жизненный цикл заезда `waiting → countdown → racing → finished → waiting`, игровой цикл `setInterval` каждые 100 мс, рассылка `state` только если `room.dirty`, рекорды в `DATA_DIR/records.json`.
- Сокет-события клиент → сервер: `join {nick, mode: quick|create|code, code}`, `start` (только хост), `progress {pos, errors}`, `leave`.
- Сервер → клиент: `state` (полное состояние комнаты + `serverNow` для синхронизации часов), `records` (топ-10).
- Сервер авторитетен: проверяет, что `pos` растёт, не больше длины текста и не быстрее `MAX_CPS` знаков/с.
- `public/app.js` вход, обработка клавиш (keydown + input для мобильных), подсветка текста, табло лобби/результатов.
- `public/track.js` класс `Track`: длинная прямая трасса во всю ширину экрана (старт слева, финиш справа), над ней одна большая трибуна. `drawRoach` рисует бегуна (вид сверху).
  Трибуна: `drawStander` рисует стоящего таракана (лапы на двухзвенной кинематике `ik`), `drawOutfit` одевает его, `cheerPose` ведёт синхронный танец группы поддержки над стартом, у финиша пресса, между ними кучки болельщиков с транспарантами (`buildCrowd`).
  Высоту сцены `layout()` считает от высоты окна и числа дорожек и сообщает в CSS через `--stage-h`. На телефоне с открытой клавиатурой (visualViewport) сцена ужимается.
  Трибуна кэшируется в отдельном холсте и перерисовывается через кадр (на слабых устройствах реже). `track.setPhase(state)` из `app.js` переключает настроение трибуны.
- Под трассой `.race-panel`: табло слева, текст справа; на телефоне текст сразу под трассой, окно в 3 строки само прокручивается за курсором.
- Мобильный ввод: скрытое поле, символы определяются сравнением старого и нового значения поля (Android набирает слово «составом»).
- `texts.js` массив текстов. Правила: без «ё», без длинного тире и кавычек-ёлочек, одна строка.

## Соглашения
- Все строки интерфейса на русском, обращение на «ты», короткие фразы, глаголы действия на кнопках.
- Палитра в `:root` в `style.css`: побелка `--whitewash`, масляная краска `--wall`, эмаль `--enamel`, жёлтый `--yolk`. Новые цвета заводить там же.
- Шрифты: Unbounded (заголовки, цифры), Golos Text (текст), JetBrains Mono (набираемый текст).
- Без фреймворков и бандлеров, пока это не станет действительно нужно.
- Состояние в памяти, поэтому только один инстанс на Amvera.

## Проверка перед коммитом
- `node --check server.js public/app.js public/track.js`
- Запустить сервер, открыть две вкладки, создать комнату, зайти во второй вкладке по коду, пройти заезд до табло результатов.

## Не коммитить
`node_modules/`, `data/`, `.env` (уже в `.gitignore`).
